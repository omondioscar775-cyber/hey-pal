# Known MVP gaps and release gates

- Production upstream host/settings, hosted MongoDB readiness, logs, and authorized smoke tests are pending. The live Vercel deployment still returned the old registration error during this investigation.
- Planner supports individual booking preview, confirmation and cancellation. The backend batch schedule API remains available for a future batch editor. The calendar form has no selector for the second occurrence of a repeated local clock time.
- Roadmap history exposes persisted drafts and approval. The existing direct approval flow remains available. Some detailed roadmap diff, recovery history and scheduling UX remains outside the new changes.
- Field Web Vitals, full WCAG conformance, cross-user testing across every new module, hosted CI, staging failover/restore and production load targets remain release gates.
- Circles, promises, billing and advanced AI remain deferred. Launch privacy and retention policies require an approved release jurisdiction and operational owner.

- Progress reports approved case counts. The defined seven-day Recovery Completion Rate and its eligibility cohort still need implementation and verification.
